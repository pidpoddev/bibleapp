# PidPod Main Website

Static homepage package for `https://pidpod.com/`.

## Brand Copy

PidPod is the software development brand of Bumfuzzle Inc., a Tennessee holding corporation.

Faith Canvas and ChalkPoint are the first two brands of PidPod.

## Files

- `index.html` - main homepage
- `styles.css` - homepage styling
- `assets/pidpod-logo.png` - AI-generated PidPod logo concept

## Deployment

Upload the contents of this folder to the web root for `pidpod.com`.

Do not upload the folder itself unless the target path should become `/pidpod-main/`.
