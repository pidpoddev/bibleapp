For families

Child Safety and Parent Guidance

Faith Canvas is built for quiet Bible reading, prayer journaling, favorites, and creative verse art. It is not a social network.

Safe

No public posting

Faith Canvas does not include public profiles, public comments, followers, or open chat.

Calm

No third-party ads

The app is intended to be a calm journaling space, not an ad-driven experience.

Private

Local by default

Journal content is stored on the device unless optional Cloud Save is turned on.

Recommended family rules

  • Use a parent-approved Secret Phrase if Cloud Save is enabled.
  • Do not write home address, school name, phone number, passwords, or private family information in journal entries.
  • Ask a parent or guardian before emailing support.
  • Use the app as a quiet reflection tool, not as a replacement for trusted adult guidance.

Report a concern

If a parent, guardian, teacher, or church leader has a concern about Faith Canvas, email support@pidpod.com.
