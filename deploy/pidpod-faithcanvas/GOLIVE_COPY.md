## Short App Description

Faith Canvas is a gentle Bible journaling app for kids and families to read Bible verses, save favorites, write prayer notes, and create soft verse art.

## Parent-Facing Privacy Summary

Faith Canvas does not sell personal information, does not use third-party advertising, and does not include public profiles, followers, open chat, public posting, or a social feed. Journal entries, favorites, verse art, app settings, and customization choices stay on the device by default. Optional Cloud Save uses a Secret Phrase to protect saved app content before it is sent to PidPod servers.

## In-App Settings Summary

Your journal, favorites, verse art, and settings stay on this device unless you choose Cloud Save. Cloud Save is optional and uses your Secret Phrase to protect saved app content before it is sent to PidPod servers. Faith Canvas has no third-party ads, public profiles, followers, open chat, or social feed.

## Data Safety Notes

- Core use stores journal entries, prayer notes, favorite verses, verse designs, themes, and app settings locally on the device.
- Optional Cloud Save stores a Cloud Save username, device identifier, recovery identifier, timestamps, and encrypted backup records.
- Support email may include whatever contact information and app details the sender chooses to provide.
- Basic technical server logs may be created when the app contacts PidPod services.
- Faith Canvas may ask for photo library permission only if the user chooses to save verse art or journal images to the device.
- Faith Canvas does not request precise location, contacts, camera, microphone, or advertising tracking permissions for its core journaling features.
- Do not ask families to email a Secret Phrase, password, home address, school name, or private journal text.

## Deletion Copy

Families can reset local journal data in Settings. To request deletion of Cloud Save records, email `support@pidpod.com` with the Cloud Save username or recovery details shown in the app. Do not email a Secret Phrase.

## Child Safety Copy

Faith Canvas is not a social network. It does not include public profiles, public comments, followers, open chat, or public posting. Children should ask a parent or guardian before using Cloud Save or contacting support.
